## 第一步：先定 Java 版还是基岩版，端口和核心完全不同

Java 版和基岩版是两套服务端程序，客户端默认也互不相通。选错版本的代价是核心、教程、端口全部白费，所以这一步要在买机器之前定下来。

|  | Java 版 | 基岩版 |
| --- | --- | --- |
| 默认端口 | 25565 | 19132 |
| 传输协议 | TCP | UDP |
| 主流核心 | 原版、Paper、Fabric、Forge、Mohist | BDS、LiteLoaderBDS、Nukkit、PMMP |

基岩版那块要特别记住：BDS 走的是 UDP，防火墙和安全组里只放 TCP 是进不去的。

Java 版内部还要再选一次核心，选错了后面装插件、装模组都会白忙。

| 核心 | 什么情况下选它 |
| --- | --- |
| 原版（官方） | 纯原版玩法，不装插件也不装模组 |
| Paper | 要插件、要性能，兼容大部分 Bukkit / Spigot 插件 |
| Fabric | 玩模组，轻量，跟进新版本快 |
| Forge | 模组生态最全，多数整合包基于它 |
| Mohist | 模组和插件都要跑；它对 Minecraft 版本的跟进通常比原版慢，用之前先确认支持到你要的版本 |

基岩版这边的选择简单些：官方 BDS 最稳，LiteLoaderBDS 是重量级插件加载器，Nukkit 用 Java 写、开源免费，PMMP 基于 PHP、可定制程度高。新手开朋友服，官方 BDS 就够了。

## 第二步：机器买多大——4 核 8G 是主推荐，2 核 4G 只是下限

开高版本 Java 服，CPU 单核性能和内存比硬盘重要得多。有教程作者把话讲得很直接：配置别低于 4 核 8G，CPU 要挑高主频、高单核性能的型号，因为高版本 Java 服很吃这两项。这不是厂商话术，Minecraft 的主线程逻辑本来就压在单核上，核心多但主频低的机器开服反而更卡。

按人数和用途倒推，大致是这样：

| 场景 | 起步配置 | 说明 |
| --- | --- | --- |
| 2～5 人，原版或轻插件 | 2 核 4G | 视距调低一些更稳，属于能跑的最低线 |
| 10 人上下，带中等插件 | 4 核 8G | 有教程估算这一档能支持 10～15 人在线，实际取决于插件数量、视距和版本 |
| 20 人以上或跑模组整合包 | 单核最强的机型，内存往上加 | 4 核 8G 往往不够，整合包的加载阶段最吃内存 |

除了 CPU 和内存，硬盘留 50GB 以上、带宽 10Mbps 起步比较稳妥，这两项主要影响地图生成速度和玩家进服时的卡顿。

**面板服还是 VPS，判断规则在这里**：只需要朋友联机、能改的配置就是 `server.properties` 那几项，买面板服；需要 root 权限、要换核心、要装模组、要开给陌生人玩，买 VPS。面板服省掉的是装系统和维护环境的时间，代价是你能操作的范围只有面板开放给你的那部分。想开公共服务器，雨云自己的教程也建议直接买 VPS。

## 第三步：Java 版从零开服

**装 JDK。** 版本对不上，服务端会直接起不来。跑 1.19 用 JDK 17，跑 1.21 用 JDK 21，1.17 及以下用 Java 8。这个对应关系会随版本变化，动手前先去你下载核心的项目页确认它要求哪个 Java。装完执行 `java -version`，能打出类似 `openjdk version "21.0.3.0.3"` 的信息就算装好了。

**下载核心并上传。** 到对应项目的下载页选版本，拿到 jar 文件，传到服务器的一个空目录里。

**写启动命令。** 以 Paper 1.21 为例，可以直接抄这条：


java -server -Xms128M -XX:MaxRAMPercentage=95.0 -Dfile.encoding=UTF-8 -Duser.country=CN -jar paper-1.21-50.jar


几个参数的含义：`-XX:MaxRAMPercentage=95.0` 限制 JVM 最多用系统内存的 95%，`-Xms128M` 是初始堆内存，`-Dfile.encoding=UTF-8` 避免中文乱码，`-Duser.country=CN` 让部分插件走国内镜像。追求简单的话也可以用 `java -Xmx7G -Xms7G -jar paper.jar nogui`，`nogui` 表示只留命令行。`-Xmx` 不要顶满物理内存，留一点给系统，8G 的机器给 7G 比较合适。

Windows 的 VPS 用批处理文件更方便，新建 `run.bat`：


@echo off
java -Xmx2G -Xms512M -jar 核心文件名.jar --nogui
pause


**同意 EULA。** 第一次启动大概率会停在 `You need to agree to the EULA in order to run the server`。打开目录里的 `eula.txt`，把 `eula=false` 改成 `true`，保存后重新启动。看到日志出现 `Done` 就是起好了。

**改 `server.properties`。** 两个高频改动：`online-mode=true` 改成 `false` 可以关掉正版验证，让没买正版的客户端也能进，代价是任何人填个 ID 就能上，公开服建议保持 `true` 再配白名单；同一台机器要跑多个服务端时，把 `server-port` 改成不同端口。改完必须重启实例才生效。

# -Xmx4G` 改成实际要用的值（比如 `-Xmx7G`），再把启动命令换成 `bash run.sh`。1.16.5 及以下版本的 Forge 不需要这一步，直接跑 jar 就行。

**想用面板管理。** MCSManager 能把这些操作搬到网页上：用官方一键脚本装好，访问 `http://服务器IP:23333/` 进面板，节点端口是 24444，这两个端口 TCP 和 UDP 都要放行。服务用 `systemctl start/stop/restart mcsm-web.service` 和 `mcsm-daemon.service` 管理。装完面板还需要在节点设置里把远程节点 IP 和端口填对，否则面板连不上实例。

**Linux 下不想装面板**，用 screen 保活最简单：`screen -S mc` 开窗口，启动服务端，按 `Ctrl+A+D` 挂起，下次 `screen -r mc` 回到后台，`screen -S mc -X quit` 关服。

## 第四步：基岩版最快的路子是面板服

基岩版手动搭也不难，下载官方 BDS 开服包、解压、改 `server.properties`、用 screen 跑起来就行。如果你只是想和朋友联机，雨云游戏云的路径更短，官方教程里写得很完整：

1. 官网点 `游戏云`，再点 `购买游戏云`；
2. 选 `Minecraft 基岩版`，在弹出菜单里选 `官方基岩版`，完成购买；
3. 回到游戏云主页，进入面板服务器实例，这里能看到面板账号和密码；
4. 点 `进入翼龙面板`，用这组账号密码登录；
5. 单击服务器标签进入管理页，点 `开机`，等实例显示出运行时间就是开服成功；
6. 游戏客户端进 `服务器` 页面，划到最底下点 `添加服务器`，面板地址冒号前的内容填地址栏，冒号后的填端口。

换存档在面板的 `文件` 里操作：进 `worlds` 文件夹，把原来的文件删干净，上传自己的存档，重启服务器。

这套流程来自 2022 年的教程，翼龙面板这几年改过版，按钮位置和名称可能和描述有出入，路径大体是这条路，具体以你当前面板为准。

## 端口与防火墙：四张网都要对得上

| 用途 | 端口 | 协议 |
| --- | --- | --- |
| Java 版服务端默认 | 25565 | TCP |
| 基岩版服务端默认 | 19132 | UDP |
| MCSManager 网页面板 | 23333 | TCP |
| MCSManager 节点守护 | 24444 | TCP 和 UDP |

放行要过两层：云厂商控制台的安全组，和系统自带的防火墙（Ubuntu 上是 ufw，CentOS 上是 firewalld）。用 NAT 共享 IP 的机型还多一层端口映射，映射出来的外网端口不一定等于 25565，玩家连接时要填映射后的端口。

新手最常踩的四个坑，按出现频率排：

- **EULA 没改**，服务端启动到一半就退出，日志里能看到提示，改 `eula.txt` 重启即可。
- **基岩版只放了 TCP**，19132 是 UDP，客户端会一直显示连接超时。
- **Java 版本不对**，服务端刚启动就报错退出，换对应版本的 JDK。
- **改了配置没重启**，`server.properties` 的改动要重启实例才加载。
